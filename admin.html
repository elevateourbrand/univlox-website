⚙️ Setup Supabase diperlukan

  1. Buat akun gratis di supabase.com
  2. Buat project baru → pergi ke Settings → API
  3. Copy Project URL dan anon public key
  4. Buka file admin.html, cari bagian ⚙️ CONFIG, isi SUPABASE_URL dan SUPABASE_ANON_KEY
  5. Buat tabel & storage bucket dengan SQL di komentar dalam file ini
  6. Lakukan hal yang sama di index.html bagian CMS_SUPABASE_URL
